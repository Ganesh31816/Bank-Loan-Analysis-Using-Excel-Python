# Bank Loan Analysis Using Excel & Python

## 📌 Project Overview

This project analyzes bank loan data using Python to understand loan applications, funded amounts, repayment performance, and borrower characteristics.

The analysis focuses on key loan performance indicators and provides insights into good loans, bad loans, lending trends, loan purposes, employment length, loan terms, and home ownership.

## 🎯 Project Objectives

- Analyze total loan applications
- Calculate Month-to-Date (MTD) loan applications
- Analyze total funded loan amounts
- Calculate MTD funded amounts
- Analyze total amount received
- Calculate MTD amount received
- Calculate average interest rate
- Calculate average Debt-to-Income (DTI) ratio
- Analyze Good Loan and Bad Loan performance
- Identify monthly lending trends
- Analyze lending activity by state
- Analyze loan terms
- Analyze employment length
- Analyze loan purposes
- Analyze home ownership
